# Правила проекта

- **Никогда не завершать процессы по имени** (`taskkill /IM`, `pkill`, `killall` и подобное). На компьютере параллельно работают другие сессии и программы. Останавливать можно только свой процесс, запущенный в этой сессии, и только по его PID (например, `taskkill /PID <pid> /T /F`).
- Адрес сайта, `base`, Telegram-username и прочие настройки хранятся только в `site.config.ts`, в коде не хардкодятся.
- Коммиты на английском. Автор в локальном git config: noreply-адрес GitHub.
- Перед сообщением об этапе: `npm test`, `npm run build`, `npm run screenshots` (посмотреть снимки в `screenshots/`) и, если менялась покупка, `npm run check:order`.
- В этой среде localhost открывается только по IPv4 (`127.0.0.1`), `localhost`/`::1` блокируются.
