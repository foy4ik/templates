# Сайт-витрина готовых шаблонов: спецификация

Дата: 2026-10-03. Источники: `ТЗ сайт готовых шаблонов.md`, `docs/decisions.md`, переписка с заказчиком.

## Цель

Статический сайт-витрина 12 шаблонов (боты, Mini App, сайты, парсеры). Три шаблона готовы к продаже, остальные «Скоро». Оплаты нет: покупка передаёт заказ в Telegram `@foy4ik`. Архитектура готова к подключению ЮKassa без переделки. Дизайн повторяет портфолио foy4ik.github.io (токены в `docs/decisions.md`).

## Стек и хостинг

- Astro (static), Content Collections + zod, обычный CSS с переменными, минимум JS (фильтр, модалка, галерея).
- GitHub Pages, деплой через GitHub Actions при push в `main`.
- Адрес `https://foy4ik.github.io/templates/`. Репозиторий `templates`.

## Конфиг: единственное место настроек

`site.config.ts`:

| Ключ | Значение сейчас | Назначение |
| --- | --- | --- |
| `siteUrl` | `https://foy4ik.github.io` | origin сайта |
| `base` | `/templates/` | путь; при переезде на домен: `/` |
| `telegramUsername` | `foy4ik` | единственный источник username, нигде не хардкодится |
| `portfolioUrl` | `https://foy4ik.github.io` | ссылка на портфолио |
| `metrikaId` | пустая строка | пусто = аналитика выключена |
| `paymentEnabled` | `false` | включение онлайн-оплаты |
| `updateMonths` | `3` | срок обновлений в варианте «Исходники» |

`astro.config.mjs` читает `siteUrl` и `base` отсюда. Все внутренние ссылки и пути к ресурсам строятся через один хелпер `url()`, который учитывает `base`. Переезд на домен = смена `siteUrl` и `base`.

## Схема данных шаблона

Файл `src/content/templates/<slug>.md`, поля во frontmatter, описание в теле. `slug` берётся из имени файла.

| Поле | Тип | `ready` | `soon` |
| --- | --- | --- | --- |
| `title`, `audience`, `short` | string | обязательны | обязательны |
| `category` | `bot \| miniapp \| site \| parser` | обязательно | обязательно |
| `status` | `ready \| soon` | обязательно | обязательно |
| `features` | string[], минимум 1 | обязательно | обязательно (планируемые) |
| `price_source`, `price_turnkey` | число, ₽ | обязательны | необязательны, на сайте не выводятся |
| `turnkey_days` | число | обязательно | необязательно, на сайте не выводится |
| `demo_url` | url | обязательно | запрещено |
| `stack`, `requirements` | string, string[] | обязательны | необязательны |
| `faq` | `{q, a}[]` | 4–6 элементов | необязательно |
| `screenshots` | image[] | по умолчанию пусто (заглушка категории) | то же |
| `video` | url | необязательно | необязательно |
| `featured` | boolean, по умолчанию false | | |
| `order` | число | порядок в каталоге | |

Правила проверяются `superRefine`: нарушение ломает сборку с названием файла и поля. Перевод шаблона из «Скоро» в «Готов»: сменить `status` и добавить `demo_url`, `stack`, `requirements`, `faq`; цены и срок уже лежат во frontmatter. Цены числа, форматирует только `lib/format.ts`.

## Страницы

| Адрес | Содержимое |
| --- | --- |
| `/` | оффер, 3–6 `featured` шаблонов, «Как это работает» (3 шага), блок индивидуальной разработки, ссылка на портфолио |
| `/catalog/` | все карточки, фильтр по категориям, порядок: готовые, затем «Скоро», внутри по `order` |
| `/templates/<slug>/` | блоки по ТЗ: заголовок и статус, демо и галерея, функции, два варианта покупки, стек и требования, FAQ, 3 карточки из той же категории. У «Скоро»: описание, планируемые функции, кнопка «Хочу этот шаблон», без цен и демо |
| `/custom/` | «Не нашли подходящий шаблон?», портфолио, кнопка в Telegram |
| `/offer/`, `/privacy/` | заголовок и пометка «текст будет добавлен» |
| `/thanks/` | «Спасибо за покупку», текст про получение файлов, `noindex` |

Шапка: логотип, «Каталог», «Под ключ» (ведёт на `/custom/`), «Портфолио», кнопка «Написать в Telegram». Подвал: контакты, оферта, политика, портфолио. Переключателя темы нет: тема по `prefers-color-scheme`, как в портфолио.

## Компоненты

- Каркас: `Header`, `Footer`, `Base` (layout).
- Ядро: `Button` (primary, ghost, sm), `Badge`, `Tag`, `SectionTitle`.
- Каталог: `TemplateCard`, `TemplateGrid` (1/2/3 колонки), `CatalogFilter` (без JS все карточки видны).
- Страница шаблона: `DemoBlock`, `Gallery` (`<dialog>` + scroll-snap), `FeatureList`, `PurchaseCard` ×2, `StackRequirements`, `Faq` (`<details>`), `RelatedTemplates`.
- Главная: `Hero`, `HowItWorks`, `CustomCta`.
- Покупка: `OrderModal` и `lib/purchase.ts`.
- SEO: `Seo` и JSON-LD.

## Покупка

`startPurchase(template, variant)`, `variant` = `source | turnkey | wish`. Единственная точка входа для всех кнопок покупки.

1. Отправляет цель в Метрику (`lib/analytics.ts`), если `metrikaId` задан; название шаблона передаётся параметром.
2. При `paymentEnabled === false` открывает `OrderModal`: название, вариант, цена, готовый текст заказа. Тексты: исходники «Здравствуйте! Хочу купить исходники шаблона «…» за N ₽», под ключ «… заказать установку под ключ … за N ₽ (от)», «Хочу этот шаблон» без цены.
3. Кнопка «Написать в Telegram» копирует текст в буфер и открывает `https://t.me/<telegramUsername>?text=<текст>`. Подсказка «Текст заказа скопирован — вставьте его в чат». Если буфер недоступен, показывается текст для ручного копирования.
4. При `paymentEnabled === true` вызывается ветка оплаты (на старте заглушка с явной ошибкой, реализуется в отдельном проекте).

Параметр `?text=` может не подставляться на некоторых клиентах; это допустимо, текст уже в буфере. Проверка на iOS, Android и Telegram Desktop выполняется заказчиком по чек-листу этапа 3 (устройств у разработчика нет; логику копирования и сборку ссылки проверю автотестом).

## SEO

- Уникальные title и description на каждой странице; для шаблона вида «Telegram-бот записи клиентов — готовый шаблон и установка под ключ».
- Open Graph и canonical с обложкой шаблона (для заглушки категории — PNG для превью; SVG в Open Graph не работает).
- Schema.org Product с двумя Offer (исходники, под ключ) только для `ready`.
- **Sitemap:** `@astrojs/sitemap` при сборке, с учётом `base`, без `/thanks/`. Файл `sitemap-index.xml`.
- **robots.txt:** endpoint `src/pages/robots.txt.ts`, не статический файл. Содержимое собирается из `siteUrl` и `base`: `User-agent: *`, `Allow: /`, `Sitemap: <siteUrl><base>sitemap-index.xml`. После переезда на домен работает без правок.
- Поисковики читают `robots.txt` только из корня домена. Пока сайт на `/templates/`, этот файл в роли robots не работает: на этапе 4 передам строку для `robots.txt` портфолио (`Sitemap: https://foy4ik.github.io/templates/sitemap-index.xml`) и напомню отправить sitemap в Яндекс Вебмастер.

## Дизайн и адаптив

Токены и шрифты из `index.html` портфолио, обе темы (см. `docs/decisions.md`); недостающие токены (тени, брейкпоинты) берутся из полного CSS портфолио на этапе 1. Mobile first: карточки 1/2/3 колонки на 375/768/1280. Крупные зоны нажатия на кнопках покупки. Скриншоты открываются во весь экран со свайпом. Без тяжёлых анимаций. Шрифты с `display=swap`.

## Ограничения и открытые вопросы

- Оплата ЮKassa, выдача исходников, переезд на Vercel/VPS не входят в этот проект.
- Тексты оферты и политики не сочиняются.
- Демо-ссылки и скриншоты на этапе 2 заглушки; в конце этапа 2 выдаётся список, что подготовить.
