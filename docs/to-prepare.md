# Что нужно подготовить

Список того, что на сайте сейчас заглушка. Обновляйте по мере готовности.

## Для каждого готового шаблона

Три шаблона со статусом `ready`. Файл шаблона: `src/content/templates/<slug>.md`.

| Шаблон | Файл | Демо (сейчас заглушка) | Скриншоты |
| --- | --- | --- | --- |
| Бот записи клиентов | `booking-bot.md` | `https://example.com/demo/booking-bot` → ссылка на живого бота | 3–5 шт. в `src/assets/shots/booking-bot/` |
| Бот-квиз для сбора заявок | `quiz-leads-bot.md` | `https://example.com/demo/quiz-leads-bot` → живой бот | 3–5 шт. в `src/assets/shots/quiz-leads-bot/` |
| Мини-апп магазин | `shop-miniapp.md` | `https://example.com/demo/shop-miniapp` → мини-апп | 3–5 шт. в `src/assets/shots/shop-miniapp/` |

- Скриншоты добавляются в поле `screenshots` файла шаблона, например `screenshots: [../../assets/shots/booking-bot/1.png]`. Пока их нет, показывается обложка-заглушка категории. Размеры: ботов — около 750×1334, сайтов и мини-аппов — около 1280×800.
- Видео (необязательно): поле `video` со ссылкой.
- Ссылки `demo_url` сейчас ведут на `example.com`. Замените на реальные до запуска.

## Общее

- 4 картинки для превью ссылок (Open Graph), 1200×630: `public/og/bot.png`, `miniapp.png`, `site.png`, `parser.png` (нужны на этапе 4; временные сгенерирую сам).
- Тексты оферты и политики конфиденциальности (на сайте страницы с пометкой «текст будет добавлен»).
- Финальные цены, сроки «под ключ» и тексты всех 12 шаблонов (сейчас осмысленные заглушки; цены у «Скоро» на сайте не видны).
- FAQ у готовых шаблонов: сейчас типовые ответы, проверьте формулировки.
- Домен (по желанию): после покупки меняется `siteUrl` и `base` в `site.config.ts`.
- Номер счётчика Яндекс Метрики: поле `metrikaId` в `site.config.ts`.
- Заявленные в описаниях «обновления на 3 месяца» берутся из `updateMonths` в `site.config.ts`.
