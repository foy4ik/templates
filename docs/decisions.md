## Поправки к дизайну (2026-10-03)

- Telegram-username только из `site.config.ts`, в коде не хардкодится. Ссылка `?text=` проверяется на iOS, Android и Telegram Desktop заказчиком на этапе 3; если текст не подставился, выручает буфер обмена
- `robots.txt` генерируется endpoint'ом (не статикой), sitemap через `@astrojs/sitemap` с учётом `base`. Пока сайт на `/templates/`, отдельно передаётся строка `Sitemap:` для robots.txt портфолио и напоминание про Яндекс Вебмастер (этап 4)
- Для `soon` поля `price_source`, `price_turnkey`, `turnkey_days` необязательны и не выводятся; для `ready` обязательны. Перевод в ready: смена `status` плюс добавление демо, стека, требований и FAQ

## Закрытие от индексации до запуска (2026-10-04)

- Флаг `indexing` в `site.config.ts`, сейчас `false`: на всех страницах `<meta name="robots" content="noindex, nofollow">`, `robots.txt` запрещает всё (`Disallow: /`). При `true` работает как в спецификации (страница «Спасибо» остаётся `noindex`).
- Тест на оба режима: `tests/seo.test.ts`.
- **Перед запуском переключить `indexing` на `true`.** Реально сайт от поисковиков защищает meta-тег: `robots.txt` по пути `/templates/` поисковики не читают (см. выше).
- Sitemap при `false` по-прежнему генерируется, но в `robots.txt` не упоминается.

## Упрощения (приняты)

- Обычный CSS с переменными, без Tailwind
- Галерея: нативный `<dialog>` + CSS `scroll-snap`, без библиотек
- Schema.org Product: два предложения (исходники, под ключ) у готовых шаблонов; у «Скоро» разметки нет
- Отдельная страница `/custom` для индивидуальной разработки
- Видео только ссылкой, без встроенного плеера
- Скрипт Метрики подключается только при заданном счётчике
- Страница «Спасибо» с `noindex`

## Дизайн-токены (из index.html портфолио)

- Тёмная: `--bg #09080d`, `--bg-elevated #121119`, `--surface #141319`, `--accent #8b6bff`, `--accent-2 #3fe8bd`, `--danger #ff6b81`, `--text #eeecf5`, `--text-dim #98939f`
- Светлая: `--bg #f5f4fa`, `--bg-elevated #fff`, `--surface #fff`, `--accent #6a3df0`, `--accent-2 #0ea88a`, `--danger #d6304a`, `--text #151420`, `--text-dim #635f72`
- Шрифты: Inter (текст), JetBrains Mono (надзаголовки, кнопки, теги)
- Карточки: радиус 16px, подъём на 4px при наведении. Кнопки: радиус 10px, `13px 22px`, варианты primary, ghost, sm
- Остальные токены (тени и др.) на этапе 1 берутся из полного CSS портфолио
