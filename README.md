# Шаблоны: сайт-витрина

Статический сайт-витрина готовых шаблонов (Telegram-боты, мини-приложения, лендинги, парсеры). Покупка пока идёт через Telegram: кнопка открывает окно с готовым текстом заказа. Сайт: <https://foy4ik.github.io/templates/>.

Стек: Astro (статическая сборка), Content Collections с проверкой полей (zod), обычный CSS, минимум JS. Хостинг: GitHub Pages, деплой через GitHub Actions при каждом push в `main`.

## Запуск

```bash
npm install
npm run dev        # разработка
npm test           # unit-тесты
npm run build      # сборка в dist/
npm run preview    # просмотр сборки
```

Проверки перед релизом:

| Команда | Что делает |
| --- | --- |
| `npm run screenshots` | собирает сайт и снимает ключевые страницы на 375/768/1280 px в обеих темах в `screenshots/` |
| `npm run check:layout` | проверяет все страницы на 3 ширинах: нет горизонтального скролла, кнопки не ниже 44 px, нет ошибок в консоли, нет запросов к сторонним хостам |
| `npm run check:order` | проходит сценарий заказа в браузере: окно, текст, ссылка, username, кнопки «Написать в Telegram» и «Скопировать текст», режим без буфера |
| `npm run lighthouse` | Lighthouse (мобильный) на 5 ключевых страницах |
| `npm run og` | пересоздаёт обложки для превью ссылок в `public/og/` |

Если команды скриншотов и Lighthouse не запускаются, один раз выполните `npx playwright install chromium`.

Шрифты (Inter и JetBrains Mono) лежат в проекте: `src/assets/fonts/`, подключение в `src/styles/fonts.css`. Сторонние сервисы не используются, `check:layout` падает при любом запросе к чужому хосту. Лицензии (SIL OFL) лежат рядом с файлами.

## Настройки: `site.config.ts`

Единственное место настроек сайта.

| Ключ | Значение сейчас | Что делает |
| --- | --- | --- |
| `siteUrl` | `https://foy4ik.github.io` | адрес сайта (для canonical, sitemap, превью) |
| `base` | `/templates/` | путь, на котором живёт сайт |
| `telegramUsername` | `foy4ik` | Telegram для заказов и кнопок «Написать» |
| `portfolioUrl` | `https://foy4ik.github.io` | ссылка на портфолио |
| `metrikaId` | пусто | номер счётчика Яндекс Метрики; пусто = аналитика выключена |
| `paymentEnabled` | `false` | включение онлайн-оплаты (ветка в `startPurchase`, пока не реализована) |
| `updateMonths` | `3` | срок обновлений в варианте «Исходники» |
| `indexing` | `false` | `false` = сайт закрыт от поисковиков; **перед запуском переключить на `true`** |

## Как добавить шаблон

1. Создайте файл `src/content/templates/<slug>.md`. Имя файла становится адресом: `/templates/<slug>/`.
2. Заполните поля в начале файла, ниже напишите описание. Страница, карточка в каталоге и фильтр появятся сами.
3. Положите скриншоты в `src/assets/shots/<slug>/` и перечислите их в поле `screenshots`. Пока их нет, показывается заглушка категории.
4. Проверьте `npm run build` (при ошибке в полях сборка покажет файл и поле) и сделайте `git push`.

```markdown
category: bot            # bot | miniapp | site | parser
status: soon
audience: Владельцы каналов, SMM
short: Копит очередь постов и публикует их в канал по расписанию.
features:
  - Очередь отложенных постов
  - Публикация по расписанию
price_source: 1490
price_turnkey: 7000
turnkey_days: 3
order: 5                 # порядок в каталоге
```

```markdown
Описание шаблона.
```

Перевод из «Скоро» в «Готов»: смените `status` на `ready` и добавьте `demo_url`, `stack`, `requirements` и `faq` из 4–6 вопросов. Цены и срок уже есть. Сборка подскажет, чего не хватает.

## Покупка и оплата

Все кнопки покупки вызывают одну функцию `startPurchase(шаблон, вариант)` (`src/lib/purchase.ts`). Сейчас она открывает окно с текстом заказа и ссылкой в Telegram. Цели Яндекс Метрики: `buy_source`, `buy_turnkey`, `want_template` (с названием шаблона). Для подключения ЮKassa нужно реализовать ветку `paymentEnabled: true` в этой функции и серверную часть (Vercel или VPS).

Открытые вопросы на этап оплаты:

- как выдавать исходники после оплаты: ссылка на скачивание с ограниченным сроком или отправка через Telegram-бота;
- подключение ЮKassa как самозанятый: проверить актуальные требования и выдачу чеков через «Мой налог»;
- куда переезжает сайт: Vercel с серверными функциями или VPS.

## Переезд на свой домен

1. В `site.config.ts` поменяйте `siteUrl` на новый адрес и `base` на `/`.
2. Добавьте файл `public/CNAME` с именем домена и настройте DNS по инструкции GitHub Pages (Settings → Pages → Custom domain).
3. `robots.txt` и sitemap подстроятся сами. Строку `Sitemap:` в `robots.txt` портфолио после переезда можно убрать.

## Запуск для поисковиков

1. Заменить заглушки: реальные `demo_url`, скриншоты, тексты оферты и политики (см. `docs/to-prepare.md`).
2. Поставить `indexing: true` в `site.config.ts`.
3. Добавить в `robots.txt` репозитория портфолио (`foy4ik.github.io`) строку `Sitemap: https://foy4ik.github.io/templates/sitemap-index.xml` (пока сайт на `/templates/`; на своём домене не нужно).
4. Отправить `sitemap-index.xml` в Яндекс Вебмастер (и по желанию в Google Search Console).
